# 关于此书

此书主要关于单机上的算法。
示例代码主要是Rust语言，因为mdbook里使用rust便于运行。

## 解决不同问题的常用利器

+ [枚举](./算法基础/枚举.md)：枚举（Enumerate）是基于已有知识来猜测答案的一种问题求解策略。 枚举的思想是不断地猜测，从可能的集合中一一尝试，然后再判断题目的条件是否成立。
+ [二分](./算法基础/二分.md)：利用结果的有序性来查找

+ [滑动窗口](./算法基础/滑动窗口.md)：需要维护多个连续数据的状态，同时多个连续数据之间能通过一边进一边出计算

+ [ST表](./数据结构/st表.md)：可重复贡献问题，如求区间最大值。可以做到\\(\Theta(n\log n)\\)预处理，\\(\Theta(1)\\)的回答查询，但不能修改
