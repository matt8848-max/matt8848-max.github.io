# 枚举

枚举（Enumerate）是基于已有知识来猜测答案的一种问题求解策略。
枚举的思想是不断地猜测，从可能的集合中一一尝试，然后再判断题目的条件是否成立。

要点：
+ 给出解空间
+ 减少不必要的枚举空间
+ 选择合适的枚举顺序

## 枚举右，维护左

对于 双变量问题，例如两数之和 \\(a_i +a_j =t\\)，可以枚举右边的\\(a_i\\) ，转化成 单变量问题，也就是在 \\(a_j\\)​  左边查找是否有 \\(a_i =t-a_j \\) ，这可以用哈希表维护。

[4074. 和为目标值的最大乘积对](https://leetcode.cn/problems/maximum-product-pair-with-target-sum/)
```rust
use std::collections::HashMap;

struct Solution;

impl Solution {
    /// 枚举右、维护左：边扫边把「值 → 下标」记进哈希表，配对时 O(1) 查表。
    fn max_product_pair(nums: Vec<i32>, target: i32) -> Vec<i32> {
        let mut pre: HashMap<i32, usize> = HashMap::new();
        let mut best = i64::MIN;
        let mut res = vec![0usize, 0];
        for (i, &x) in nums.iter().enumerate() {
            let need = target - x;
            // 两个下标不能相同（need != x），且左边确实出现过 need
            if need != x {
                if let Some(&j) = pre.get(&need) {
                    let product = x as i64 * need as i64;
                    if product > best {
                        best = product;
                        res = vec![i, j];
                    }
                }
            }
            // 后出现的下标覆盖前面的：此时 i 更靠右，留给后面的元素用更合适
            pre.insert(x, i);
        }
        // 题目要求按值从小到大给出这两个下标对应的元素顺序
        if nums[res[0]] < nums[res[1]] {
            res.swap(0, 1);
        }
        res.into_iter().map(|i| i as i32).collect()
    }
}

fn main() {
    // 1 + 6 = 7（乘积 6），2 + 5 = 7（乘积 10），取后者
    println!("{:?}", Solution::max_product_pair(vec![1, 2, 5, 6], 7));
}
```

此题特殊，实际上是先来一个“枚举右，维护左”，然后来个“枚举左，维护右”，但是这两个操作可以合并
[2078. 两栋颜色不同且距离最远的房子](https://leetcode.cn/problems/two-furthest-houses-with-different-colors/)
```rust
struct Solution;

impl Solution {
    /// 首尾颜色不同时，整段长度就是答案的最大值；
    /// 首尾相同时，只需找最靠左、最靠右的异色房子。
    fn max_distance(colors: Vec<i32>) -> i32 {
        let n = colors.len();
        if colors[0] != colors[n - 1] {
            return n as i32 - 1;
        }
        let target = colors[0];
        let mut ans = 0;
        for (i, &x) in colors.iter().enumerate() {
            if x != target {
                // 与最左端、最右端分别配一次，取较远的那边
                ans = ans.max(i as i32).max(n as i32 - 1 - i as i32);
            }
        }
        ans
    }
}

fn main() {
    // 最远的异色对是下标 0（颜色 1）与下标 3（颜色 6），距离 3
    println!("{}", Solution::max_distance(vec![1, 1, 1, 6, 1, 1, 1]));
}
```

## 枚举中间

对于有三个或者四个变量的问题，枚举中间的变量往往更好算。

为什么？比如问题有三个下标，需要满足 \\(0\leq i\lt j\lt k\lt n\\)，对比一下：

+ 枚举 i，后续计算中还需保证 \\(j\lt k\\)。
    + 枚举 k 同理。
+ 枚举 j，那么 i 和 k 自动被 j 隔开，互相独立，后续计算中无需关心 i 和 k 的位置关系。

所以枚举中间的变量更简单。

[3583. 统计特殊三元组](https://leetcode.cn/problems/count-special-triplets/)

此题利用哈希维护左右两侧
```rust
use std::collections::HashMap;

struct Solution;

impl Solution {
    /// 枚举中间项：先统计全部频次当作「右侧」，扫过的元素再挪到「左侧」。
    fn special_triplets(nums: Vec<i32>) -> i32 {
        const MOD: i64 = 1_000_000_007;
        let mut right: HashMap<i32, i64> = HashMap::new();
        for &x in &nums {
            *right.entry(x).or_insert(0) += 1;
        }
        let mut left: HashMap<i32, i64> = HashMap::new();
        let mut ans: i64 = 0;
        for &x in &nums {
            // 当前元素先退出右侧，这样左右两侧才严格不含当前下标
            if let Some(count) = right.get_mut(&x) {
                *count -= 1;
            }
            // 以 x 为中间项时，左右各取一个 2x 就构成一组特殊三元组
            let left_count = left.get(&(x * 2)).copied().unwrap_or(0);
            let right_count = right.get(&(x * 2)).copied().unwrap_or(0);
            ans = (ans + left_count * right_count) % MOD;
            *left.entry(x).or_insert(0) += 1;
        }
        ans as i32
    }
}

fn main() {
    // 唯一解是 (6, 3, 6)：中间项 3，两侧都是 2 * 3 = 6
    println!("{}", Solution::special_triplets(vec![6, 3, 6]));
}
```


[456. 132 模式](https://leetcode.cn/problems/132-pattern/)

此题利用单调栈维护右侧，枚举左侧和中间
```rust
struct Solution;

impl Solution {
    /// 从右往左扫，用单调栈维护「2 的候选」，second 记录已经找到的次大值：
    /// 一旦左侧出现比 second 更小的数，就凑成了 1 < 3 > 2 且 1 < 2 的 132 模式。
    fn find132pattern(nums: Vec<i32>) -> bool {
        let n = nums.len();
        let mut stack: Vec<i32> = vec![nums[n - 1]]; // 从栈底到栈顶递减
        let mut second = i32::MIN;
        for i in (0..n - 1).rev() {
            let current = nums[i];
            // 当前值能当 1
            if current < second {
                return true;
            }
            // 当前值当 3：比它小的候选都能被它「盖住」，被弹出的那个就是新的 2
            while let Some(&top) = stack.last() {
                if top >= current {
                    break;
                }
                second = second.max(stack.pop().expect("栈非空"));
            }
            // 当前值也可能作为 2 的候选留在栈里
            if current > second {
                stack.push(current);
            }
        }
        false
    }
}

fn main() {
    println!("{}", Solution::find132pattern(vec![1, 2, 3, 4])); // false
    println!("{}", Solution::find132pattern(vec![3, 1, 4, 2])); // true
}
```
