# 二分

## 二分查找
二分查找（binary search），也称折半搜索（half-interval search）、对数搜索（logarithmic search），是用来在一个有序序列中查找某一元素的算法。
+ 它每次访问数组当前部分的中间元素，如果中间元素刚好是要找的，就结束搜索过程
+ 如果中间元素小于所查找的值，那么左侧的元素都不大于中间元素，不可能有所查找的元素，只需到右侧查找
+ 如果中间元素大于所查找的值同理，只需到左侧查找

时间复杂度：
+ 最优\\(O(1)\\)
+ 平均\\(O(\log n)\\)

[704. 二分查找](https://leetcode.cn/problems/binary-search/)
```rust
struct Solution;

impl Solution {
    /// 闭区间写法：`right` 表示还没被排除的右端点。
    /// 循环结束时 `left` 恰好是第一个不小于 `target` 的下标。
    fn search(nums: Vec<i32>, target: i32) -> i32 {
        let mut left: i64 = 0;
        let mut right: i64 = nums.len() as i64 - 1;
        while left <= right {
            let mid = (left + right) / 2; // left、right 都小于 n，相加不会溢出
            if nums[mid as usize] < target {
                left = mid + 1; // 中间值偏小，答案只可能在右半边
            } else {
                right = mid - 1; // 中间值不小于目标，答案在左半边（含 mid）
            }
        }
        // 结束时 right + 1 == left，再确认 left 没越界且正好命中
        if left < nums.len() as i64 && nums[left as usize] == target {
            left as i32
        } else {
            -1
        }
    }
}

fn main() {
    let nums = vec![-1, 0, 3, 5, 9, 12];
    println!("{}", Solution::search(nums.clone(), 9)); // 4
    println!("{}", Solution::search(nums, 2)); // -1
}
```

## 二分答案
二分答案是利用问题答案的广义有序性质（通常也被称为单调性），通过类似二分查找的方式快速求出答案的算法

能够利用二分答案的问题通常形如**求满足条件P的最大（小）值**，并具有如下性质：
+ 如果给出任意数 x，容易判断 x 是否满足条件
+ 问题的答案可以划定一个粗略的上下界，即可以确定 L 和 R 使得若答案 x 存在，则 x 必然满足 \\(L\leq x \leq R\\)
+ 划定的粗略的上下界范围很大，一个个枚举并且判断会超时；
+ 条件 P 具有广义的有序性质

假设存在一个函数f(x)，当且仅当 x 满足条件 P 时 f(x)=1，否则 f(x)=0，
则可以用下列方式定义条件 P 的广义有序性质：
- 若对于任意的 \\(L \le i < j \le R\\)，\\(f(i) \le f(j)\\)，即 \\(f(x)\\) 单调不减. 将 \\(i = L, \dots, R\\) 的 \\(f(i)\\) 写成一个 01 序列时形如 `00...011...1`. 此时二分答案可以求出满足条件 \\(P\\) 的 **最小值**
- 若对于任意的 \\(L \le i < j \le R\\)，\\(f(i) \ge f(j)\\)，即 \\(f(x)\\) 单调不增. 对应的 01 序列形如 `11...100...0`. 此时二分答案可以求出满足条件 \\(P\\) 的 **最大值**

换言之，第一种有序性质是指：如果知道 \\(x\\) 满足条件 \\(P\\)，则所有比 \\(x\\) 大的数一定都满足条件 \\(P\\). 二分答案可以求出符合「比它小的数都不满足条件 \\(P\\)，它和比它大的数都满足条件 \\(P\\)」这一描述的 \\(x\\).

而第二种有序性质是指：如果知道 \\(x\\) 满足条件 \\(P\\)，则所有比 \\(x\\) 小的数一定都满足条件 \\(P\\). 二分答案可以求出符合「它和比它小的数都满足条件 \\(P\\)，比它大的数都不满足条件 \\(P\\)」这一描述的 \\(x\\).

证明一种写法正确，需要确认：
+ 初始化满足循环不变量．
+ 每次更新都保持不变量，并使待搜索区间中的整数个数严格减少，从而保证循环最终结束．
+ 循环结束时，能够由不变量和终止条件确定返回值就是答案；若允许无解，还需说明如何识别无解情况．


>什么是循环不变量？
>
> 想一想，对于求最小的题目，开区间二分的写法，为什么最终返回的是 right，而不是别的数？在初始化（循环之前）、循环中、循环结束后，都时时刻刻保证 check(right) == true 和 check(left) == false，这就叫循环不变量。根据循环不变量，循环结束时 left+1=right，那么 right 就是最小的满足要求的数（因为再 −1 就不满足要求了），所以答案是 right。

### 求最小
[4008. 击败所有怪物的最小初始强度](https://leetcode.cn/problems/minimum-initial-strength-to-defeat-all-monsters/)
```rust
struct Solution;

impl Solution {
    /// 二分答案：初始强度越大越容易成功，满足单调性，于是二分「最小的可行强度」。
    fn min_initial_strength(monsters: Vec<i64>, boosts: Vec<Vec<i64>>) -> i64 {
        let n = monsters.len();
        // 差分数组还原每只怪物的增益：区间 [l, r] 加 v 等价于 l 处 +v、r+1 处 -v
        let mut bonus = vec![0i64; n + 1];
        for b in &boosts {
            let (l, r) = (b[0] as usize, b[1] as usize);
            bonus[l] += b[2];
            bonus[r + 1] -= b[2];
        }
        for i in 1..n {
            bonus[i] += bonus[i - 1];
        }

        // check：给定初始强度，能否按顺序打完全部怪物
        let check = |init: i64| -> bool {
            let mut hp = init;
            for (x, buff) in monsters.iter().zip(bonus.iter()) {
                if hp + buff < *x {
                    return false; // 这一只就已经打不过
                }
                // 血量降到 0 就停下，不会变成负数
                hp = (hp - x).max(0);
            }
            true
        };

        // 可行答案不会超过所有怪物生命之和，二分区间取 [0, 生命之和]
        let (mut low, mut high) = (0i64, monsters.iter().sum::<i64>());
        while low <= high {
            let mid = (low + high) / 2;
            if check(mid) {
                high = mid - 1; // 可行，尝试更小的强度
            } else {
                low = mid + 1; // 不可行，必须更大
            }
        }
        low
    }
}

fn main() {
    // 强度 7 才够：7 打掉 3 剩 4；4 + 2 打掉 2 剩 2；2 + 2 刚好打掉 4
    println!("{}", Solution::min_initial_strength(vec![3, 2, 4], vec![vec![0, 2, 2]])); // 7
}
```

[3639. 变为活跃状态的最小时间](https://leetcode.cn/problems/minimum-time-to-activate-string/)
```rust
struct Solution;

impl Solution {
    /// 二分答案：激活前 m + 1 个位置后，能否凑出至少 k 个「全激活」子串。
    fn min_time(_s: String, order: Vec<i32>, k: i32) -> i32 {
        let n = order.len();
        let k = k as i64;
        // 全部激活也只有 n*(n+1)/2 个非空子串，凑不够直接返回 -1
        if n as i64 * (n as i64 + 1) / 2 < k {
            return -1;
        }

        // star 记录「激活时的步数标记」，省去每次 check 都清空数组：
        // 只有等于本次标记的位置才算激活，历史标记自然失效
        let mut star = vec![0usize; n];
        let mut check = |m: usize| -> bool {
            let mark = m + 1;
            for &idx in order.iter().take(mark) {
                star[idx as usize] = mark;
            }
            // 扫一遍：以 i 结尾的全激活子串个数 = 最近一次激活位置 + 1
            let mut count: i64 = 0;
            let mut last: i64 = -1;
            for (i, x) in star.iter().enumerate() {
                if *x == mark {
                    last = i as i64;
                }
                count += last + 1;
                if count >= k {
                    return true;
                }
            }
            false
        };

        // 二分最小的可行步数（下标 0 表示只激活第一个位置）；
        // 用 i64 做边界，避免 high 降到 -1 时无符号数下溢
        let (mut low, mut high) = (0i64, n as i64 - 1);
        while low <= high {
            let mid = (low + high) / 2;
            if check(mid as usize) {
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        low as i32
    }
}

fn main() {
    // 激活下标 0 之后，单个字符就是 1 个全激活子串，已经够了
    println!("{}", Solution::min_time("abc".to_string(), vec![0, 1, 2], 1)); // 0
}
```
### 求最大
请注意「求最小」和「求最大」在二分写法上的区别。

「求最小」和二分查找求「排序数组中某元素的第一个位置」是类似的，按照红蓝染色法，左边是不满足要求的（红色），右边则是满足要求的（蓝色）。

「求最大」的题目则相反，左边是满足要求的（蓝色），右边是不满足要求的（红色）。这会导致二分写法和上面的「求最小」有一些区别。

以开区间二分为例：

求最小：check(mid) == true 时更新 right = mid，反之更新 left = mid，最后返回 right。
求最大：check(mid) == true 时更新 left = mid，反之更新 right = mid，最后返回 left。
对于开区间写法，简单来说 check(mid) == true 时更新的是谁，最后就返回谁。相比其他二分写法，开区间写法不需要思考加一减一等细节，推荐使用开区间写二分。

[275. H 指数 II](https://leetcode.cn/problems/h-index-ii/)
```rust
struct Solution;

impl Solution {
    /// 二分答案：h 指数越大越难满足，满足单调性，用开区间二分求最大值。
    fn h_index(citations: Vec<i32>) -> i32 {
        let n = citations.len();
        // check：是否存在至少 m 篇论文的引用数不小于 m
        let check = |m: i64| -> bool {
            // 二分出第一篇引用数 >= m 的位置，它右边的篇数（含自己）记作 n - right
            let mut left: i64 = -1;
            let mut right: i64 = n as i64;
            while left + 1 < right {
                let mid = (left + right) / 2;
                if citations[mid as usize] as i64 >= m {
                    right = mid;
                } else {
                    left = mid;
                }
            }
            n as i64 - right >= m
        };

        // 开区间二分求最大：check 为真就抬高下界，最后返回 left
        let mut left: i64 = 0; // check(0) 恒为真
        let mut right: i64 = n as i64 + 1; // check(n+1) 恒为假
        while left + 1 < right {
            let mid = (left + right) / 2;
            if check(mid) {
                left = mid;
            } else {
                right = mid;
            }
        }
        left as i32
    }
}

fn main() {
    // 引用数 [0, 1, 3, 5, 6]：3 篇论文引用数不小于 3，故 h 指数为 3
    println!("{}", Solution::h_index(vec![0, 1, 3, 5, 6])); // 3
}
```

### 二分间接值
[3143. 正方形中的最多点数](https://leetcode.cn/problems/maximum-points-inside-the-square/)
```rust
struct Solution;

impl Solution {
    /// 二分边长：边长为 2*size 的正方形里一旦出现重复字母就不能再扩大，
    /// 所以「是否可行」关于 size 单调，可以二分边界。
    fn max_points_inside_square(points: Vec<Vec<i32>>, s: String) -> i32 {
        let letters: Vec<char> = s.chars().collect();
        // Some(点数) 表示该边长下没有重复字母；None 表示已经冲突
        let evaluate = |size: i32| -> Option<i32> {
            let mut seen = [false; 26];
            let mut count = 0;
            for (p, ch) in points.iter().zip(letters.iter()) {
                if p[0].abs() <= size && p[1].abs() <= size {
                    let idx = (*ch as u8 - b'a') as usize;
                    if seen[idx] {
                        return None; // 同一字母出现两次，这个边长不可行
                    }
                    seen[idx] = true;
                    count += 1;
                }
            }
            Some(count)
        };

        // 二分最后一个合法边长：left 始终合法，right 始终非法
        let mut left: i64 = -1;
        let mut right: i64 = 1_000_000_001; // 坐标绝对值不超过 1e9，必然非法
        let mut best = 0;
        while left + 1 < right {
            let mid = (left + right) / 2;
            match evaluate(mid as i32) {
                Some(count) => {
                    best = count;
                    left = mid;
                }
                None => right = mid,
            }
        }
        best
    }
}

fn main() {
    // size = 1（边长 2）时两个点都在正方形内，且字母不同，共 2 个点
    println!(
        "{}",
        Solution::max_points_inside_square(vec![vec![0, 0], vec![1, 0]], "ab".to_string())
    ); // 2
}
```
这题更好点的解法是直接记录最小和次小（这不是二分方法）
```rust
use std::collections::HashMap;

struct Solution;

impl Solution {
    /// 不开二分的写法：每个字母只记录它到原点的切比雪夫距离（即所需的最小边长）；
    /// 同一个字母第二次出现时，就得到了「再大就冲突」的上界 limit。
    fn max_points_inside_square(points: Vec<Vec<i32>>, s: String) -> i32 {
        let letters: Vec<char> = s.chars().collect();
        let mut limit = i32::MAX; // 上界：边长达到它就一定会出现重复字母
        let mut dist: HashMap<char, i32> = HashMap::new();
        for (p, ch) in points.iter().zip(letters.iter()) {
            // 落在正方形内要求 |x| <= size 且 |y| <= size，故只需记录较大的那个绝对值
            let size = p[0].abs().max(p[1].abs());
            if size >= limit {
                continue; // 已经在上界之外，不可能被纳入，直接剪枝
            }
            match dist.get_mut(ch) {
                None => {
                    dist.insert(*ch, size);
                }
                Some(old) => {
                    // 同一字母的两个点要同时纳入，边长至少取较大者；超过它就是冲突
                    limit = limit.min((*old).max(size));
                    *old = (*old).min(size);
                }
            }
        }
        // 只有所需边长严格小于 limit 的字母才能全部放进去
        dist.values().filter(|v| **v < limit).count() as i32
    }
}

fn main() {
    println!(
        "{}",
        Solution::max_points_inside_square(vec![vec![0, 0], vec![1, 0]], "ab".to_string())
    ); // 2
}
```


### 最小化最大值
[410. 分割数组的最大值](https://leetcode.cn/problems/split-array-largest-sum/)
```rust
struct Solution;

impl Solution {
    /// 最小化最大值：二分「每段和的上限 m」，判断能否切成不超过 k 段。
    fn split_array(nums: Vec<i64>, k: i64) -> i64 {
        let check = |m: i64| -> bool {
            let mut count = 0;
            let mut total = 0;
            for x in nums.iter() {
                if total + x > m {
                    // 加上就超了，只能在这里切一刀，新的一段从 x 开始
                    count += 1;
                    total = *x;
                } else {
                    total += x;
                }
            }
            if total > 0 {
                count += 1; // 最后一段
            }
            count <= k
        };

        // 下界取「最大元素 - 1」：一定不可行；上界取「总和 + 1」：一定可行
        let mut low = nums.iter().copied().max().unwrap_or(0) - 1;
        let mut high = nums.iter().sum::<i64>() + 1;
        while low + 1 < high {
            let mid = (low + high) / 2;
            if check(mid) {
                high = mid; // 可行，试着把上限压低
            } else {
                low = mid; // 不可行，必须放大上限
            }
        }
        high
    }
}

fn main() {
    // 切成 [7,2,5] 与 [10,8]，两段和分别是 14、18，最大值为 18
    println!("{}", Solution::split_array(vec![7, 2, 5, 10, 8], 2)); // 18
}
```

### 最大化最小值
[3620. 恢复网络路径](https://leetcode.cn/problems/network-recovery-pathways/)

题目描述有点绕，就是要求，有效路径的所有边应该大于等于结果
```rust
struct Solution;

impl Solution {
    /// 最大化最小值：二分「路径上允许的最小边权」，判断 0 到 n-1 是否存在花费不超过 k 的路径。
    fn find_max_path_score(edges: Vec<Vec<i32>>, online: Vec<bool>, k: i64) -> i32 {
        let n = online.len();
        // 只保留两端都可用（online）的边
        let mut graph: Vec<Vec<(usize, i64)>> = vec![Vec::new(); n];
        let mut max_weight = -1i64;
        for e in &edges {
            let (x, y, w) = (e[0] as usize, e[1] as usize, e[2] as i64);
            if online[x] && online[y] {
                graph[x].push((y, w));
                if x == 0 {
                    max_weight = max_weight.max(w);
                }
            }
        }

        // check：只走权值不小于 lower 的边，求 0 到 n-1 的最小花费
        let check = |lower: i64| -> bool {
            // 记忆化：每个点只算一次，避免重复搜索同一子问题
            let mut memo = vec![None::<i64>; n];
            memo[n - 1] = Some(0);
            // 用普通递归 + 显式 memo，代替 Python 的 @cache
            fn dfs(
                x: usize,
                graph: &[Vec<(usize, i64)>],
                lower: i64,
                memo: &mut Vec<Option<i64>>,
            ) -> i64 {
                if let Some(best) = memo[x] {
                    return best;
                }
                let mut best = i64::MAX; // 表示走不通
                for &(y, w) in &graph[x] {
                    if w >= lower {
                        let sub = dfs(y, graph, lower, memo);
                        if sub != i64::MAX {
                            best = best.min(sub + w);
                        }
                    }
                }
                memo[x] = Some(best);
                best
            }
            let cost = dfs(0, &graph, lower, &mut memo);
            cost != i64::MAX && cost <= k
        };

        // 开区间二分求最大：left 可行、right 不可行，最后返回 left
        let mut left = -1i64;
        let mut right = max_weight + 1;
        while left + 1 < right {
            let mid = (left + right) / 2;
            if check(mid) {
                left = mid;
            } else {
                right = mid;
            }
        }
        left as i32
    }
}

fn main() {
    // 有两条路径：0->1->3 花费 8，0->2->3 花费 4；
    // 边权下限取 2 时仍走第二条（4 <= 6），取 3 就只能走第一条（8 > 6）
    let edges = vec![
        vec![0, 1, 4],
        vec![1, 3, 4],
        vec![0, 2, 2],
        vec![2, 3, 2],
    ];
    println!("{}", Solution::find_max_path_score(edges, vec![true; 4], 6)); // 2
}
```
### 第K大/小
例如数组 [1,1,1,2,2]，其中第 1 小、第 2 小和第 3 小的数都是 1，第 4 小和第 5 小的数都是 2。

对于第 k 小/大问题，有如下转化套路：
+ 第 k 小等价于：求最小的 x，满足 \\(\leq\\)x 的数至少有 k 个。
+ 第 k 大等价于：求最大的 x，满足 \\(\geq\\)x 的数至少有 k 个。

[668. 乘法表中第k小的数](https://leetcode.cn/problems/kth-smallest-number-in-multiplication-table/)
```rust
struct Solution;

impl Solution {
    /// 第 k 小 ⇔ 求最小的 x，使「不大于 x 的数至少有 k 个」。
    fn find_kth_number(m: i32, n: i32, k: i32) -> i32 {
        let (m, n, k) = (m as i64, n as i64, k as i64);
        let check = |mid: i64| -> bool {
            // 第 i 行是 i、2i、…、ni，其中不大于 mid 的有 min(mid / i, n) 个；
            // 前 mid / n 行整行都满足，可以先一次性算掉
            let mut count = mid / n * n;
            for i in mid / n + 1..=m {
                count += mid / i;
            }
            count >= k
        };

        // 开区间二分：low 一定不满足，high 一定满足
        let mut low = 0i64;
        let mut high = m * n;
        while low + 1 < high {
            let mid = (low + high) / 2;
            if check(mid) {
                high = mid;
            } else {
                low = mid;
            }
        }
        high as i32
    }
}

fn main() {
    // 3×3 乘法表排序后为 1、2、2、3、3、4、6、6、9，第 5 小是 3
    println!("{}", Solution::find_kth_number(3, 3, 5)); // 3
}
```

### 三分法

如果需要求出单峰函数的极值点，通常需要使用三分法（ternary search）


[1515. 服务中心的最佳位置](https://leetcode.cn/problems/best-position-for-a-service-centre/)
```rust
struct Solution;

impl Solution {
    /// 三分法：距离和关于中心坐标是凸函数，先固定 x 三分 y，再对 x 三分。
    fn get_min_dist_sum(positions: Vec<Vec<i32>>) -> f64 {
        // 给定候选中心，求所有点到它的欧氏距离之和
        let dist = |xc: f64, yc: f64| -> f64 {
            positions
                .iter()
                .map(|p| {
                    let dx = p[0] as f64 - xc;
                    let dy = p[1] as f64 - yc;
                    (dx * dx + dy * dy).sqrt()
                })
                .sum()
        };

        // 内层：固定 x，三分 y 找出最优纵坐标及其距离和
        let best_y = |xc: f64| -> f64 {
            let (mut low, mut high) = (0.0f64, 100.0f64);
            while high - low > 1e-9 {
                let y1 = low + (high - low) / 3.0;
                let y2 = high - (high - low) / 3.0;
                if dist(xc, y1) < dist(xc, y2) {
                    high = y2; // 极小值在左半边
                } else {
                    low = y1; // 极小值在右半边
                }
            }
            dist(xc, low)
        };

        // 外层：对 x 三分
        let (mut low, mut high) = (0.0f64, 100.0f64);
        while high - low > 1e-9 {
            let x1 = low + (high - low) / 3.0;
            let x2 = high - (high - low) / 3.0;
            if best_y(x1) < best_y(x2) {
                high = x2;
            } else {
                low = x1;
            }
        }
        best_y(low)
    }
}

fn main() {
    // 只有一个点 (0, 0)：中心取它本身，距离和为 0
    println!("{:.5}", Solution::get_min_dist_sum(vec![vec![0, 0]])); // 0.00000
}
```
