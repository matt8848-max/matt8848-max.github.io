
# 滑动窗口

## 定长滑动窗口

窗口右端点在 i 时，由于窗口长度为 k，所以窗口左端点为 i−k+1。
+ 入：
    + 下标为 i 的元素进入窗口，更新相关统计量。
    + 如果窗口左端点 i−k+1<0，说明尚未形成第一个窗口，重复第一步。
+ 更新状态：
    + 此时窗口长度为 k，符合题目要求，用状态计算更新答案。
+ 出：
    + 下标为 i−k+1 的元素离开窗口，更新状态，为下一个循环做准备

> 注：元素离开窗口后，窗口长度为 k−1。下一轮循环元素进入窗口后，窗口长度为 k。

以上三步适用于所有定长滑窗题目。

[1456. 定长子串中元音的最大数目](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/description/)


```rust
/// 1456. 定长子串中元音的最大数目
fn max_vowels(s: &str, k: usize) -> usize {
    /// 只有 5 个元音，用 `matches!` 判断比构造集合更省事。
    fn is_vowel(c: char) -> bool {
        matches!(c, 'a' | 'e' | 'i' | 'o' | 'u')
    }

    let chars: Vec<char> = s.chars().collect();
    let mut ans = 0;
    let mut cnt = 0;
    // 左端点初始为 `-k`：前 k 个字符还没凑成一个完整窗口，此时左端点「在字符串外」。
    // 用 `i64` 表示负数下标，避免下溢。
    let mut l: i64 = -(k as i64);

    for r in 0..chars.len() {
        // 入：右端点字符进入窗口，更新元音计数
        if is_vowel(chars[r]) {
            cnt += 1;
        }
        l += 1;

        if l >= 0 {
            // 更新状态：此时窗口长度恰好为 k，可以用当前计数更新答案
            ans = ans.max(cnt);
            // 出：左端点字符离开窗口，为下一轮循环做准备
            if is_vowel(chars[l as usize]) {
                cnt -= 1;
            }
        }
    }

    ans
}

fn main() {
    // 示例数据取自 LeetCode 1456
    println!("{}", max_vowels("abciiidef", 3));
    println!("{}", max_vowels("aeiou", 2));
}
```

[3679. 使库存平衡的最少丢弃次数](https://leetcode.cn/problems/minimum-discards-to-balance-inventory/description/)

```rust
use std::collections::HashMap;

/// 3679. 使库存平衡的最少丢弃次数
fn min_arrivals_to_discard(arrivals: &[i32], w: usize, m: i32) -> i32 {
    // 需要「就地丢弃」，所以先拷贝一份可变数据
    let mut arrivals = arrivals.to_vec();
    // 键是商品编号，值是它在当前窗口内的到达次数
    let mut cnt: HashMap<i32, i32> = HashMap::new();
    let mut ans = 0;
    let mut l: i64 = -(w as i64);

    for r in 0..arrivals.len() {
        let a = arrivals[r];
        // 入：0 表示这一次到达已被丢弃，不参与统计
        if a > 0 {
            *cnt.entry(a).or_insert(0) += 1;
        }
        l += 1;

        // 利用状态计算答案：窗口内同一个值的到达次数超过 m，就贪心地丢掉这一次
        if *cnt.get(&a).unwrap_or(&0) > m {
            cnt.insert(a, m);
            arrivals[r] = 0;
            ans += 1;
        }

        // 出：左端点对应的到达离开窗口
        if l >= 0 {
            let out = arrivals[l as usize];
            *cnt.entry(out).or_insert(0) -= 1;
        }
    }

    ans
}

fn main() {
    // 示例数据：w 为窗口长度，m 为窗口内同一商品允许的最大到达次数
    println!("{}", min_arrivals_to_discard(&[1, 2, 1, 1, 1, 2], 3, 2));
    println!("{}", min_arrivals_to_discard(&[3, 1, 3, 3, 2], 2, 2));
}
```

## 不定长滑动窗口

不定长滑动窗口主要分为三类：求最长子数组，求最短子数组，求子数组个数。

### 越短越合法/求最长/最大

[3634. 使数组平衡的最少移除数目](https://leetcode.cn/problems/minimum-removals-to-balance-array/)
```rust
/// 3634. 使数组平衡的最少移除数目
fn min_removal(nums: &[i32], k: i32) -> usize {
    if nums.is_empty() {
        return 0;
    }

    // 排序后，「最大值 / 最小值 <= k」的那段数一定是连续区间，于是转成滑窗
    let mut nums = nums.to_vec();
    nums.sort_unstable();

    let mut ans = 1; // 至少能留下 1 个数
    let mut l = 0;
    for r in 0..nums.len() {
        // 先用 i64 承接乘法，避免 i32 溢出
        let x = nums[r] as i64;
        // 越短越合法：收缩左端点直到窗口重新合法（l <= r 保证不会越界）
        while l <= r && x > nums[l] as i64 * k as i64 {
            l += 1;
        }
        ans = ans.max(r - l + 1);
    }

    nums.len() - ans
}

fn main() {
    // 示例数据：移除的数目 = 总数 - 能保留的最长合法窗口长度
    println!("{}", min_removal(&[1, 6, 2, 9], 3));
    println!("{}", min_removal(&[2, 1, 5], 2));
}
```

### 越长越合法/求最短/最小

[3795. 不同元素和至少为 K 的最短子数组长度](https://leetcode.cn/problems/minimum-subarray-length-with-distinct-sum-at-least-k/)
```rust
use std::collections::HashMap;

/// 3795. 不同元素和至少为 K 的最短子数组长度
fn min_length(nums: &[i32], k: i64) -> i32 {
    // 「不同元素和」把同一个取值只算一次，所以既要计数，又要单独维护这个和
    let mut cnt: HashMap<i32, i32> = HashMap::new();
    let mut s: i64 = 0;
    let mut l = 0usize;
    let mut ans: Option<usize> = None;

    for r in 0..nums.len() {
        let x = nums[r];
        let c = cnt.entry(x).or_insert(0);
        // 第一次出现才计入「不同元素和」
        if *c == 0 {
            s += x as i64;
        }
        *c += 1;

        // 越长越合法：收缩左端点，收缩前的那个长度就是当前右端点的最优解
        while s >= k {
            let len = r - l + 1;
            ans = Some(match ans {
                None => len,
                Some(best) => best.min(len),
            });

            let out = nums[l];
            let c2 = cnt.entry(out).or_insert(0);
            *c2 -= 1;
            if *c2 == 0 {
                s -= out as i64;
            }
            l += 1;
        }
    }

    // 始终没凑出合法窗口就返回 -1
    ans.map_or(-1, |best| best as i32)
}

fn main() {
    // 示例数据：k 为「不同元素和」的下限
    println!("{}", min_length(&[1, 2, 3, 4, 5], 9));
    println!("{}", min_length(&[1, 1, 1], 5));
}
```

### 求子数组个数
#### 越短越合法

一般要写 ans += right - left + 1。

内层循环结束后，[left,right] 这个子数组是满足题目要求的。由于子数组越短，越能满足题目要求，所以除了 [left,right]，还有 [left+1,right],[left+2,right],…,[right,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 left,left+1,left+2,…,right 的所有子数组都是满足要求的，这一共有 right−left+1 个。

[713. 乘积小于 K 的子数组](https://leetcode.cn/problems/subarray-product-less-than-k/)
```rust
/// 713. 乘积小于 K 的子数组
fn num_subarray_product_less_than_k(nums: &[i32], k: i64) -> i32 {
    let mut ans: i64 = 0;
    let mut l = 0usize;
    let mut s: i64 = 1; // 窗口内所有元素的乘积

    for r in 0..nums.len() {
        // 入：右端点元素进入窗口（样例不含 0，故下面的除法不会除零）
        s *= nums[r] as i64;

        // 越短越合法：乘积过大就收缩左端点
        while s >= k && l <= r {
            s /= nums[l] as i64;
            l += 1;
        }

        // 以 r 为右端点、左端点在 [l, r] 内的子数组都满足要求；`l > r` 时取得 0
        ans += (r as i64 - l as i64 + 1).max(0);
    }

    ans as i32
}

fn main() {
    println!("{}", num_subarray_product_less_than_k(&[10, 5, 2, 6], 100));
    // k <= 1 时没有任何子数组乘积更小，结果应为 0
    println!("{}", num_subarray_product_less_than_k(&[1, 2, 3], 0));
}
```
#### 越长越合法
一般要写 ans += left。

内层循环结束后，[left,right] 这个子数组是不满足题目要求的，但在退出循环之前的最后一轮循环，[left−1,right] 是满足题目要求的。由于子数组越长，越能满足题目要求，所以除了 [left−1,right]，还有 [left−2,right],[left−3,right],…,[0,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 0,1,2,…,left−1 的所有子数组都是满足要求的，这一共有 left 个。

我们关注的是 left−1 的合法性，而不是 left。

[2062. 统计字符串中的元音子字符串](https://leetcode.cn/problems/count-vowel-substrings-of-a-string/)

```rust
use std::collections::HashMap;

/// 2062. 统计字符串中的元音子字符串
fn count_vowel_substrings(word: &str) -> i32 {
    /// 五个元音的判定。
    fn is_vowel(c: char) -> bool {
        matches!(c, 'a' | 'e' | 'i' | 'o' | 'u')
    }

    let chars: Vec<char> = word.chars().collect();
    // 键是元音，值是它在窗口内出现的次数；长度为 5 时说明 5 个元音都齐了
    let mut cnt: HashMap<char, i32> = HashMap::new();
    let mut ans = 0;
    let mut l = 0usize;
    // start 记录当前这段「连续元音」的起点，遇到辅音就重置
    let mut start = 0usize;

    for r in 0..chars.len() {
        let ch = chars[r];

        // 辅音把字符串切段，之前攒下的窗口全部作废
        if !is_vowel(ch) {
            cnt.clear();
            start = r + 1;
            l = r + 1;
            continue;
        }

        *cnt.entry(ch).or_insert(0) += 1;
        while cnt.len() == 5 {
            let out = chars[l];
            // 名额先用完 borrow 再判断是否要移除键，避免同时持有可变借用
            let rest = {
                let c = cnt.entry(out).or_insert(0);
                *c -= 1;
                *c
            };
            if rest == 0 {
                cnt.remove(&out);
            }
            l += 1;
        }

        // 越长越合法：左端点在 [start, l-1] 时，窗口都包含全部 5 个元音
        ans += (l - start) as i32;
    }

    ans
}

fn main() {
    println!("{}", count_vowel_substrings("aeiouu"));
    println!("{}", count_vowel_substrings("unicornarihan"));
}
```
#### 恰好型滑动窗口

例如，要计算有多少个元素和恰好等于 k 的子数组，可以把问题变成：
+ 计算有多少个元素和 \\(\geq k\\) 的子数组。
+ 计算有多少个元素和 \\(\gt k\\)，也就是\\(\geq k+1\\)的子数组。

答案就是元素和 \\(\geq k\\) 的子数组个数，减去元素和 \\(\geq k+1\\) 的子数组个数。
这里把 \\(\gt\\) 转换成 \\(\geq\\)，从而可以把滑窗逻辑封装成一个函数 `solve`，然后用 `solve(k)`−`solve(k+1)` 计算，无需编写两份滑窗代码。


注：也可以把两个滑动窗口合并起来，维护同一个右端点 right 和两个左端点 left_1  和 left_2

[930. 和相同的二元子数组](https://leetcode.cn/problems/binary-subarrays-with-sum/)
```rust
/// 930. 和相同的二元子数组
fn num_subarrays_with_sum(nums: &[i32], goal: i64) -> i32 {
    let mut ans: i64 = 0;
    // s1 / l1 对应「和 >= goal」的边界，s2 / l2 对应「和 > goal」的边界
    let mut s1: i64 = 0;
    let mut s2: i64 = 0;
    let mut l1 = 0usize;
    let mut l2 = 0usize;

    for r in 0..nums.len() {
        let x = nums[r] as i64;

        s1 += x;
        while l1 <= r && s1 >= goal {
            s1 -= nums[l1] as i64;
            l1 += 1;
        }

        s2 += x;
        while s2 > goal {
            s2 -= nums[l2] as i64;
            l2 += 1;
        }

        // 恰好型滑窗：左端点在 [l2, l1) 的窗口，其元素和恰好等于 goal
        ans += l1 as i64 - l2 as i64;
    }

    ans as i32
}

fn main() {
    println!("{}", num_subarrays_with_sum(&[1, 0, 1, 0, 1], 2));
    println!("{}", num_subarrays_with_sum(&[0, 0, 0, 0, 0], 0));
}
```

[3859. 统计包含 K 个不同整数的子数组](https://leetcode.cn/problems/count-subarrays-with-k-distinct-integers/)

此题的相减对象容易判断错误。
```rust
use std::collections::HashMap;

/// 3859. 统计包含 K 个不同整数的子数组
///
/// 「恰好 k 个不同整数」= 「至少 k 个」- 「至少 k+1 个」，
/// 于是把滑窗逻辑封装成 `calc`，两次相减即可，无需写两份代码。
fn count_subarrays(nums: &[i32], k: i32, m: i32) -> i32 {
    calc(nums, k, k, m) - calc(nums, k + 1, k, m)
}

/// 右端点固定时，问有多少个左端点满足：窗口内不同整数个数不超过 `limit`，
/// 且「出现次数恰好为 `m`」的取值个数不少于 `k`。
fn calc(nums: &[i32], limit: i32, k: i32, m: i32) -> i32 {
    let mut cnt: HashMap<i32, i32> = HashMap::new();
    let mut ans = 0;
    let mut l = 0usize;
    // good 记录窗口内「出现次数恰好为 m」的取值个数
    let mut good = 0;

    for r in 0..nums.len() {
        let x = nums[r];
        let c = cnt.entry(x).or_insert(0);
        *c += 1;
        if *c == m {
            good += 1;
        }

        while cnt.len() as i32 >= limit && good >= k {
            let out = nums[l];
            let rest = {
                let c = cnt.entry(out).or_insert(0);
                // 离开窗口前先看它是不是从「恰好 m 次」掉下去的
                if *c == m {
                    good -= 1;
                }
                *c -= 1;
                *c
            };
            if rest == 0 {
                cnt.remove(&out);
            }
            l += 1;
        }

        ans += l as i32;
    }

    ans
}

fn main() {
    // 示例数据：k 个不同整数，且每个都恰好出现 m 次
    println!("{}", count_subarrays(&[1, 2, 3, 1, 2, 3, 1, 2], 2, 2));
    println!("{}", count_subarrays(&[1, 1, 1], 1, 1));
}
```
