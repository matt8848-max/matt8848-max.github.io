## 滑动窗口

### 定长滑动窗口

窗口右端点在 i 时，由于窗口长度为 k，所以窗口左端点为 i−k+1。
+ 入：
    + 下标为 i 的元素进入窗口，更新相关统计量。
    + 如果窗口左端点 i−k+1<0，说明尚未形成第一个窗口，重复第一步。
+ 更新状态：
    + 此时窗口长度为 k，符合题目要求，用状态计算更新答案。
+ 出：
    + 下标为 i−k+1 的元素离开窗口，更新状态，为下一个循环做准备

> 注：元素离开窗口后，窗口长度为 k−1。下一轮循环元素进入窗口后，窗口长度为 k。

以上三步适用于所有定长滑窗题目。

[1456. 定长子串中元音的最大数目](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/description/)


```Python
TARGETS = ["a", "e", "i", "o", "u"]


class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        ans = 0

        cnt = 0
        L = -k
        for R, ch in enumerate(s):
            if ch in TARGETS:
                cnt += 1
            L += 1

            if L >= 0:
                ans = max(ans, cnt)
                if s[L] in TARGETS:
                    cnt -= 1

        return ans
```

[3679. 使库存平衡的最少丢弃次数](https://leetcode.cn/problems/minimum-discards-to-balance-inventory/description/)

```Python
class Solution:
    def minArrivalsToDiscard(self, arrivals: List[int], w: int, m: int) -> int:
        ans = 0

        cnt = defaultdict(int)
        L = -w
        for R, a in enumerate(arrivals):
            #入
            if a > 0:
                cnt[a] += 1
            L += 1
            #利用状态计算答案
            if cnt[a] > m:
                cnt[a] = m
                arrivals[R] = 0
                ans += 1 # 贪心的选择丢弃
            #出
            if L >= 0:
                cnt[arrivals[L]] -= 1

        return ans
```
