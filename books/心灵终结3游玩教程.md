# Steam版或EA版红警2玩心灵终结3教程

前言：
steam版或EA版的尤里的复仇的版本号为1.006 TUC，而心灵终结3.3.6所使用的ares是适配的1.006。

因此你需要单独下载新版ares。

安装：
+ 复制一份红警2的文件到一个新的位置，避免EA或者Steam执行文件修复。
+ 在[心灵终结官网](https://mentalomega.com/index.php?page=download)下载MOD。
+ 安装心灵终结。
+ 下载最新的[ares](https://launchpad.net/ares/+download)
+ 安装ares。

那么现在你可以游玩了
