# 游戏王MD关于效果发动、执行的检查
游戏王MD在发动前会检查发动条件，如果发动条件不能满足不能发动。如果发效果是此效果变成另一张卡的发动时的效果相同，也要检查，构成一个链式检查链。
> 查时的状态是当前场面，并除开cost

> 链式检查链通过了，才会允许你执行

> 至于执行时重新满足了某分支的条件，那么可以执行


例子1：魔女工艺的杰妮+庆典，除外区有一张下级。

+ 若此时满足庆典1效果分支中的炸卡分支，那么就能通过检查链，系统会允许你发动除外效果来执行庆典。此时进入分支选择，系统此时发现能满足融合条件，你就能选择融合
+ 若不满足炸卡分支，检查不通过，你就无法发动效果来融合

例子2：闪刀墓地2魔，空场，开交闪，连锁旋风炸交闪。此时能3魔抽1

1. 交闪的发动条件满足，能发动效果，因此能开交闪
2. 旋风条件满足，能发动效果，C2旋风
3. 执行
4. C2处理后，墓地3魔
5. C1交闪检索后，墓地3魔满足，会抽1

例子3：狂惑落穴先破坏对方的冰剑龙，然后满足除外的条件，除外冰剑龙。此时冰剑龙不能发动遗言。

+ 冰剑龙被破坏进入墓地后，此时MD会记录冰剑龙的遗言的发动位置
+ 冰剑龙随后被除外后，位置发生了改变
+ 狂惑落穴处理完后，冰剑龙的位置与记录的位置不同，无法发动
